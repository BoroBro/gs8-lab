# GS8 Lab — опыты по магнитоле GAC GS8

Песочница для экспериментов на штатной магнитоле GAC GS8 (2023, без CarPlay),
прошивка V3.1-20230925, Android 9. Пакет `com.gs8.lab`.

## GNSS-диагностика (первый модуль)

Показывает реальное качество GPS на головном устройстве:
- спутники по созвездиям (GPS / **GLONASS** / BeiDou / Galileo / QZSS / SBAS),
  сколько видно и сколько используется в фиксе;
- C/N0 (макс/среднее), TTFF (время до первого фикса);
- текущий фикс: координаты, точность, скорость, высота, провайдер;
- состояние GPS-провайдера и разрешения.

Кнопка **«Отправить фикс в HUR»** (и чекбокс авто-отправки) шлёт текущие
координаты в Headunit Revived через интент
`com.andrerinas.headunitrevived.LOCATION_UPDATE` — проверка проброса GPS
в Android Auto напрямую, минуя штатный провайдер.

## Установка
APK — в разделе **Releases**. Разрешение локации приложение запрашивает само,
либо выдать с ПК:
```
adb install -r app-release.apk
adb shell pm grant com.gs8.lab android.permission.ACCESS_FINE_LOCATION
```

Анализ GPS прошивки и план — в `gs8-wheel-keys/docs/gps.md`.
